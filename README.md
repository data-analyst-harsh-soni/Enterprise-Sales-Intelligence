## 🧠 Project Overview

This project represents a **complete, real-world data analytics workflow**. Unlike standard portfolio projects that use pre-cleaned Kaggle datasets, **I designed and generated the entire dataset from scratch using Python.**

The goal was to simulate enterprise-scale data complexity, including creating relational tables, enforcing integrity constraints, and modeling a Star Schema for high-performance reporting.

---

## 🏗️ unique Value: Self-Generated Dataset

Most analysts skip the data creation phase. I chose to build it to demonstrate **Data Modeling & Engineering skills**.

* **Logic:** `CREATE OWN DATASET.ipynb` (Python Script included)
* **Complexity:** * Generated multiple **Fact** & **Dimension** tables.
    * Enforced **Primary-Foreign Key** relationships.
    * Simulated realistic business scenarios (returns, discounts, regional demand).
* **Architecture:** Designed specifically for a **Star Schema** data model.

> *This mirrors real industry scenarios where analysts must understand the data structure at the source level.*

## 📈 Key Business Insights Derived

1.  **The "Bronze" Trap:** Bronze-tier customers contribute nearly **50% of total profit**, indicating a reliance on volume over high-value contracts.
2.  **Volume vs. Margin:** High Cost of Goods Sold (COGS) is currently being offset by massive sales volume, but margins are tight.
3.  **Risk Assessment:** Profit concentration is heavily skewed towards specific regions; a localized economic downturn could impact global revenue.
4.  **Operational Efficiency:** Certain shipping routes are underperforming, increasing the return rate due to damaged goods.
